Thank you sincerely for using 9xCraft Launcher;

-- 9xCraft is designed for Java 5 SE and above. To run a game of minecraft, you will need to provide
your own .jar files. You can add said jars to the "Versions" folder which is located in the
launcher's core directory. Alternatively, you can select "File" --> "Open .jar" in the top menu
to point to the path of a Minecraft .jar client on your computer to open it directly without 
the need to move it into the Versions folder. 
-- The versions list can arrange versions by: 
"Pre_Classic" -> "4k" -> "Classic" -> "Indev" -> "Infdev" -> "Alpha" -> "Beta" -> "Release", 
if your .jar files start with these strings in their file name, you can use this
hierarchy to keep all your versions easily accessible and organized.

You can find client jars on https://minecraft.wiki.

alternatively you can download my entire version archive here: 
https://drive.google.com/file/d/1dgqpMPD1pGVR84oZUjpKLXVvxKzWkD1F/view?usp=sharing
[might be slightly outdated]


¦¦¦¦¦¦¦¦¦¦¦¦*Additions, Bug Fixes and Changes*¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦


Initially, I wasn't planning to ever release another version of this launcher, but when i noticed today
that betacraft's servers shut down, I realized that, in case this were permanent, and since this
launcher originally relied on the betacraft Dhttp proxy, which was hard-coded into the launcher's
java parameters, I thought that perhaps I should give everybody a better and more reliable experience
by making Minecraft fetch its resources locally instead of a website.

This eventually also turned out to entirely fix the issue where versions ranging from 0.31 to late Indev
wouldn't function at all when using the launcher offline.

Furthermore, I added a local skin library which you can access by going to Options -> Skins.
In the same menu, there's now also the options to enable dark mode (though experimental)
and the option to shrink or expand the boundaries of windows inside or parented to the main launcher
to give you a better viewing experience depending on your display resolution.

Current known issues include Classic versions with SFX and music not producing any sounds on Linux.


¦¦¦¦¦¦¦¦¦¦¦¦¦¦*Usage*¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦¦


In case you're interested in creating a desktop shortcut to the launcher, there's a "launcher.ico" and
a "launcher_alt.ico" file inside the natives folder for you to use.
Note that linux (and maybe other platforms) don't support this for shortcuts, so you might have to
convert them to a .png file first.

If you're wondering how to exit older versions without a "Quit" button in the menu when
launching in fullscreen mode, simply press Alt+F4, sometimes it may take a while for the window
to close, but it should eventually do just that.

A few more notes: Older Minecraft instances ARE NOT ABLE TO SAVE WORLDS when using Java 5 SE.
This is fixed by using Java 6 SE or above.

IMPORTANT: DO NOT INSTALL THE JAVA 6 SE RUNTIME ENVIRONMENT ON WINDOWS 98, WHEN THE JDK 6 INSTALLER
PROMPTS YOU WHAT TO INSTALL, ALWAYS UNCHECK THE RUNTIME ENVIRONMENT. IT WILL BREAK THIS LAUNCHER
AND YOUR ENTIRE JAVA CONTROL PANEL UNLESS YOU UNINSTALL IT AND USE JRE 5 AGAIN. NOTE: I still
highly recommend installing JDK 6, though as mentioned, DO NOT INSTALL THE JRE WHEN PROMPTED.

Another thing, every single version of the 9xCraft Launcher has been recompiled on February 18th, 2026
to utilize an LWJGL-fork that runs on MicrosoftTM Windows© 95 and above, it's called MiniJGL and
you can check it out at https://github.com/Vulpovile/MiniJGL. This fixes absolute
incompatibility with DOS-based Windows operating systems where previously it
would get stuck on a white screen and throw a path error in the log console.
